# Architecture Decision Records (ADR)

> Append-only. 큰 아키텍처/스택 결정을 시간순으로 기록. PM·backend가 추가. **Sprint 0 스택 결정이 첫 엔트리가 된다.**

## ADR 양식
```markdown
## YYYY-MM-DD — <결정 제목>
### Context
<왜 필요한가 — 1–2문단>
### Decision
<무엇을 결정했나>
### Consequences
- Good: ...
- Tradeoffs: ...
- Future impact: ...
### Alternatives Considered
- <대안> — <기각 이유>

By: <pm|backend> · Sprint <N>
```
