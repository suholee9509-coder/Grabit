# docs/design/ — 디자인 SoT (Source of Truth, '무엇')

Grabit UI는 **Figma에 픽스(90%+ 확정)**돼 있다. 이 디렉토리는 그 고정 디자인을 가리키는 **포인터 + 인벤토리**다. (디자인을 *생성*하지 않는다 — Figma가 1차 SoT.)

> 흐름: Figma(무엇) + `docs/source/`(왜·스코프) → PM이 스펙 역설계(`docs/units/<slug>/spec.md`) → frontend가 **Figma MCP로 프레임 연동 → 픽셀-퍼펙트 퍼블리싱** → QA 충실도 검증 → 게이트 ⓒ 사인오프.

## ★ MVP 스코프 필터 (게이트 ⓐ 확정 2026-06-15) — 아래 인벤토리에 적용
- ❌ **제외**: AI 전면(어시스턴트 패널·AI 요약·AI 노트 탭) · 대시보드(차트 + GNB 대시보드 탭) · 결제/구독(요금제 모달·결제·페이월·구독관리) · 아티클 클리핑/하이라이트(**영상 전용**) · 연간 플랜.
- ✅ **포함**: u0 디자인시스템 **풀 추출**(토큰·그림자 등 모든 스타일·컴포넌트 → 시스템화) **먼저** → 그 파운데이션으로 **없는 UI/페이지(빈·로딩·에러·설정·계정·알림 등)를 채워** 구현.
- 인벤토리의 `⚠AI`·대시보드(§9)·결제(§10)·아티클 항목은 **MVP 비대상**(백로그). u5/u9/u10 = OUT, u11-settings-account = 디자인 공백 채움 단위.
