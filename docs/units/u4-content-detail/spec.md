## L1 User Story  (검증의 north star — 각 인수기준이 여기로 추적된다)
- **L1-a** As a 사용자, 콘텐츠 상세에서 영상을 임베드 플레이어로 재생하고 제목·작성자·플랫폼·업로드일·그랩 수·태그 등 메타를 확인할 수 있다 — so that 클립한(또는 추천받은) 콘텐츠를 한곳에서 깊게 소비한다.
- **L1-b** As a 사용자, 플레이어 타임라인 위 **클립 밀도 히트맵/마커**로 다른 사람들이 많이 그랩한 구간을 한눈에 보고, 마커/`가장 인기있는 구간` 카드를 클릭하면 **해당 시점부터 재생**된다 — so that 영상에서 무엇이 중요한지 집단지성으로 빠르게 판단한다.
- **L1-c** As a 사용자, 우측 소셜 사이드바에서 **인사이트(=다른 사용자의 공개 클립: 구간+메모, 직업+연차로 익명화)**를 시간순/시점순으로 열람하고, `인상깊게 본 인사이트`·`이 컨텐츠를 [코호트]가 많이 봤어요`로 코호트 시그널을 확인한다 — so that FOMO를 데이터(또래 트렌드)로 전환한다.
- **L1-d** As a 사용자, 상세 상단의 **`시청 정보` / `원본 소스` underline 탭**을 전환해 시청 정보 탭(플레이어·히트맵·인기구간·인사이트·비슷한 컨텐츠)과 원본 소스 탭(원본 컨텐츠 정보: 제목·상세 정보·원본 링크)을 오갈 수 있다.
- **L1-e** As a 사용자, 콘텐츠에 **원본 링크 이동·좋아요·클립 추가** 액션을 하고, 우측 사이드바를 **펼침(450)/접힘(60) 토글**해 본문 폭을 조절할 수 있다.
- **L1-f** As a 사용자, `비슷한 컨텐츠` 캐러셀에서 연관 콘텐츠를 탐색하고 클릭해 다른 상세로 이동할 수 있다.

**Production acceptance (관찰가능):** prod-like(로컬 Supabase + 시드)에서 사용자가 `/content/:id` 진입 → 영상이 YouTube iframe으로 재생되고, 히트맵 마커 클릭 시 플레이어가 해당 초로 seek되며, 우측 사이드바 인사이트 카드가 **u0b sanitized read(직업+연차 코호트, 실명/user_id 미노출, N<임계 코호트 숨김)**로 채워지고, `시청 정보`↔`원본 소스` 탭 전환·사이드바 펼침/접힘이 동작한다. QA가 e2e로 재현. AI 패널·아티클 경로·결제 표면 없음.

**프레임 실측 결과(2087:12538):** 우측 `사이드바_우측`(2557:23064)은 ① `작성` 버튼(버튼_38px_Short) ② `인사이트(16)` 탭 + ~~`AI 노트` 탭~~ ③ collapse 토글 ④ **댓글/답글 카드 스택**(작성자 `수호/이수호`·`하성/이하성`·`종원/손종원` 등 *실명+이니셜*·`N년차 직군`·인용 메모·구간 `10:11~12:42`·좋아요 `3`·`답글 3개 모두 보기`·`1시간 전`)으로 구성. 좌측 본문의 `인상깊게 본 인사이트`/`가장 인기있는 구간`은 **공개 클립(구간+메모, 코호트 익명)**과 일치.

**핵심 충돌:** ADR-0002는 클립의 공개 노출을 **익명(직업+연차) sanitized read**로 락했는데, 우측 사이드바 댓글 카드는 **실명+이니셜 아바타·답글(스레드)·시점앵커**를 보여준다 → 이는 *클립의 익명 집계*와 **다른 표면**(소셜 토론/댓글 레이어). 즉 두 개의 공개 모델이 공존:
- (A) **인사이트 = 공개 클립**(구간+메모, 코호트 익명) — u0b `content_clips_public`로 *흡수* 가능. **추가 엔티티 불필요.**
- (B) **댓글/답글 = 신규 소셜 엔티티**(시점앵커 노트 + 실명/아바타 + 답글 스레드 + 좋아요) — ADR-0002에 **미모델링**. `annotations`(시점앵커 공개노트) + `annotation_replies` + `likes`가 필요할 수 있음.

✅ **PM/사용자 결정(2026-06-15): 옵션 1 채택** — 인사이트=공개클립만 u0b 계약(`content_clips_public`)으로 BE 배선. 우측 댓글/답글·`작성`은 **픽셀퍼펙트 UI + 데이터 목킹/비활성**(데이터패스 차단). `annotations`(+replies+likes) 엔티티·실명노출 정책은 **ADR-0003 후보 신규 단위로 다음 스프린트 분리**. → 본 단위는 u0b 계약만으로 L1-a~f 충족, 누출 리스크 0.
