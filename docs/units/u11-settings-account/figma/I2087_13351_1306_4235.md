## 4. u11 계정메뉴 / 수신함 부착 지점

### 진입점 2종 (기존 sidebar — 훼손 금지·소비)
1. **GNB 프로필 카드 = 계정메뉴 진입점** (본 노드)
   - 구현: `Sidebar` 위젯의 `profile` prop + `onProfileClick` 콜백.
   - sidebar.tsx:162 `<button className={styles.profileCard} onClick={onProfileClick}>`.
   - **u11 부착**: 셸/앱 레이어에서 `Sidebar`의 `onProfileClick`에 **계정메뉴 팝오버/시트 오픈** 핸들러를 연결. sidebar 위젯 자체는 미수정.
2. **수신함 nav 항목 = 수신함 진입점**
   - 구현: `Sidebar`의 `MENU` 4탭 중 `inbox`(★FD1) — sidebar.tsx:65 `{ key:'inbox', label:'수신함', icon:<InboxIcon/> }`.
   - **u11 부착**: `onMenuSelect('inbox')` / `activeMenu='inbox'` 를 라우팅에 연결해 **수신함 화면**으로 진입. sidebar 위젯 미수정.

### u11 신규 화면 (전용 Figma 프레임 없음 = 디자인 공백)
계정메뉴 팝오버 콘텐츠, 설정, 프로필 수정, 로그아웃 확인, 탈퇴, 수신함 본문, 알림 — **전부 전용 프레임 없음**.
→ 발명 금지. **u0 파운데이션(`tokens.css`)·`shared/ui`(Avatar·Button 등) 컴포넌트로만** 픽셀-퍼펙트 구성. 추측 비주얼 금지, 파운데이션 일관 유지.
계정메뉴 시각 기준점 = 본 프로필 카드의 토큰 셋(border-subtle / radius-10 / text-primary / premium-green / space-4·6)을 그대로 승계.
