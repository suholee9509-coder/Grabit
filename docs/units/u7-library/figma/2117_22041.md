### 7-2. 갭(신규 검토 — 기존 토큰에 없거나 1:1 아님)
1. **폴더 select 버튼 radius 6 vs 검색바 100**: 라이브러리 검색바는 pill(100)인데, tokens의 `--radius-search`는 80(홈 검색바). **라이브러리 검색바 = 100**이므로 `--radius-pill` 사용(80 아님). 갭 아님, 주의.
2. **`rgba(102,255,75,0.12)`** (폴더추가 카드 아이콘 원형 bg) — 토큰 미보유. brand-primary 12% 틴트. 후보: `--color-brand-primary-12: rgba(102,255,75,0.12)`. (기존 `--color-brand-primary-50`만 존재.)
3. **`rgba(0,0,0,0.32)`** (썸네일 소스배지 bg) + **backdrop blur(2px)** — 토큰 미보유. 후보: `--color-overlay-black-32: rgba(0,0,0,0.32)` (`--color-overlay-black-60`만 존재). blur(2px)는 effect 토큰 없음 → 인라인.
4. **폴더 select chevron 색 `#5E5E5E`** = `--color-stroke-500` (있음, 재사용).
5. **카드 그림자**: 컨텐츠 카드 자체엔 그림자 측정 없음(`effect` 없음). 썸네일 소스배지만 blur. tokens `--shadow-card`는 본 프레임 미사용.
6. **타이포 lh 변형 주의**: 출처칩 카운트 6/2/2는 lh **160%**(`style_U6Y710`), 16/8은 lh **130%**(`style_L148CP`) — 동일 14px/Regular인데 lineHeight 다름. 픽셀-퍼펙트엔 둘 다 14px Regular로 충분(시각 차 미미)하나 실측상 분기. 토큰: `--text-body-3`(14/20≈130%)·body류로 커버, 별도 토큰 불필요.
7. **그리드 열 수**: 역할 명세 "2열" ↔ Figma 실측 "행당 5열(fill)". → **Figma 실측(5열) 우선**. 카드 폭 fill, 행 gap28·그룹 gap42·행내 gap28. (CLAUDE.md 충돌규칙: 무엇=Figma.)

> 신규 토큰 제안(2건): `--color-brand-primary-12: rgba(102,255,75,0.12)` · `--color-overlay-black-32: rgba(0,0,0,0.32)`. 나머지는 전부 기존 토큰으로 픽셀-퍼펙트 매칭 가능.
