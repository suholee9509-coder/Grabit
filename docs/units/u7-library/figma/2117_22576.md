**토큰 갭 / 주의(GAP — PM 확인 대상):**
1. **`내 라이브러리` 제목 색 `#FFFFFF`(순백)** vs `--color-text-primary`=`#FAFAFA`. 사용자 결정(2026-06-15) "모든 흰=#FAFAFA"와 충돌. → 충실도 우선이면 순백 별도(`--color-white-pure` 이미 존재, #FFFFFF), 통일 규칙이면 #FAFAFA. `라이브러리` 본문 제목·`컨텐츠`/`내 컨텐츠` 선택탭 글자도 동일 `#FFFFFF`.
2. **`폴더 추가` + 원형 fill `rgba(102,255,75,.12)`**(브랜드 12% soft) — tokens.css 미보유. 라이브러리 폴더카드 전용 → 신규 토큰 후보 `--color-brand-primary-12: rgba(102,255,75,.12)` (기존 `--color-brand-primary-50`만 존재).
3. **재생 오버레이 `rgba(0,0,0,.32)`** — `--color-overlay-black-60`(.6)과 불일치. 썸네일 재생배지 전용 → 신규 후보 `--color-overlay-black-32`.
4. **카운트 텍스트 `#505050`(선택 출처칩 카운트)** = `--color-chip-count-selected` 이미 매칭(정확). 좌사이드바 폴더리스트 선택행 카운트는 `#ECECEC`(gray-700)로 별개.
5. 본문 요소가 auto-layout 아닌 절대좌표 묶음 → 구현 시 §0 권장대로 컨테이너+세로스택 재구성(폭 1437 / 좌 inset 40).
