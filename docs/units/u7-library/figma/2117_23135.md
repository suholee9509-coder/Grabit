- 8 → `--radius-md` (셸/사이드 베이스·톱바·컨텐츠추가 버튼·사이드 콘텐츠카드)
- 4 → `--radius-xs` (사이드 카드 썸네일 102×58)
- 100 → `--radius-pill` (검색바·토글·로그인pill)
- 10 → `--radius-10` (좌레일 아바타 프레임)
- 12 → `--radius-lg` (우측 peek 폴더카드 172×172, 비주력)

### 8-3. spacing / size — 매칭 OK
- gap 4/6/8/14/16/28/42, padding 4·8×12·10×12·10×14·12×10·8/16/8/13 — `--space-*` 스케일에 존재(42는 그리드 행간, 토큰 미보유 시 직접 42px 사용).
- 검색바 h38 → `--size-search-sm` (38px, radius100). ✔
- 토글 h36/칩 h28/h32 — 측정 직사용.
- ⚠ **그리드 행간 gap 42px**: `--space-*`에 40(`--space-20`)·48 있으나 **42 미보유** → 직접 `42px` 또는 신규 토큰 후보.

### 8-4. 타이포 — 매칭 / 주의
- 폴더명 Bold 28/lh130 → `--text-title-2-size`(28, line 130%) ✔
- 내 라이브러리 Bold 20/lh130 → `--text-title-4-size`(20) ✔
- 그리드 카드 제목 Medium 15/lh130 → body-2(15)와 size 일치하나 **lh 130%**(body-2 토큰 lh22≈146%) → 직접 지정 필요.
- 사이드 카드 제목 SemiBold 14/lh130, 출처칩 라벨 Medium 14/lh130~160 혼재, 태그칩 Reg 13/lh160(`--text-chip-tag`) → 컴포넌트 타입 셋과 부분 매칭. ls는 -2%/-2.5% 혼재 → 원문대로.

### 8-5. ★ 토큰 갭 (신규/주의 후보)
1. **`rgba(0,0,0,0.32)`** — 그리드 카드 duration 배지 bg. 현 토큰 `--color-overlay-black-60`(0.6)뿐 → **overlay-black-32 신규 후보**. (※ backdrop blur(2px)는 별도 effect.)
2. **그리드 행간 42px** — `--space-*` 미보유(40/48만). 직접값 또는 `--space-grid-row` 신규.
3. **백드롭 blur(2px)** — duration 배지 `backdrop-filter: blur(2px)`(`effect_J8YEVH`). 토큰화 안 됨 → 컴포넌트 직접 지정.
4. 흰색 정책: 본 프레임 `#FFFFFF`(폴더명/토글선택) vs 토큰 `--color-white`(#FAFAFA). 통일 정책 적용 시 fidelity 검증에서 #FAFAFA 허용.
