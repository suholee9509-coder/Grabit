1. **히어로 그라데이션 마스크** `linear-gradient(-90deg, rgba(10,10,10,0)→rgba(10,10,10,1))` — 토큰엔 18,18,18 기반(`fill_4BHDTI`)만 존재. 10,10,10 기반 추가 필요.
2. **인사이트/그랩 카드 shadow** `0px 4px 16px rgba(0,0,0,0.24)` (트렌드 카드) — 토큰 미보유 (overlay=0 8 24, drop=0 4 4).
3. **인사이트 직군 라벨색**: `#8777FF`(violet, fill_VNK3HM) · `#B472D0`(magenta, fill_IS6U2G) — 토큰의 accent-violet(#727AD0)/없음과 불일치 → 신규.
4. **순백 #FFFFFF** 2건: 탭 언더라인(2px)·트렌드 카드 제목 — 토큰 흰색은 모두 `#FAFAFA`(FD3). 픽셀-퍼펙트엔 #FFFFFF 필요.
5. **콘텐츠 좌 inset 26px** (그랩/인사이트/트렌드 그룹) — 4px 베이스 외, 토큰 미보유.
6. 셸 장식(우측 Sparkle FAB 44×44 / AI Sidebar / footer Nav)은 **본 피드 단위 구현 범위 아님**(게이트 ⓐ 제외).
