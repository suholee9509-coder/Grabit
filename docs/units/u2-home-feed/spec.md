## L1 User Story  (검증의 north star — 각 인수기준이 여기로 추적된다)
- **L1-a** As a 회원, 홈 진입 시 **취향관(기본)** 에서 *내 직군이 많이 본 콘텐츠(Grabit 엄선)* 와 *직군별 크로스 트렌드* 를 발견해서, "지금 무엇을 봐야 하나"의 막막함(FOMO)을 줄인다.
- **L1-b** As a 회원, 홈 상단의 **취향관/피드 세그먼트 토글**로 큐레이션(취향관)과 실시간 흐름(피드)을 전환하며 탐색한다.
- **L1-c** As a 회원, **피드** 탭에서 카테고리 칩(전체/AI/기획/UXUI 디자인/프론트엔드/백엔드/마케팅)으로 분야를 좁혀 *분야별 트렌드·실시간 인기 그랩·현직자 인사이트* 를 본다.
- **L1-d** As a 회원, **직군별 크로스 트렌드** 섹션에서 다른 관심분야 칩(데이터 사이언스/프론트엔드/마케팅 …)을 선택하면 그 분야의 추천 캐러셀로 *재필터* 된다.
- **L1-e** As a 회원, 콘텐츠 카드를 클릭하면 **콘텐츠 상세(u4)** 로 이동한다(라우팅만 — 상세 화면은 u4).
- **L1-f** As a 회원, 추천/트렌드 데이터가 **0건(콜드스타트)** 이거나 로딩/에러일 때, 죽은 화면 대신 일관된 빈/로딩/에러 상태(파운데이션)와 콜드스타트 폴백(전역 인기·에디토리얼 시드·내 관심사 기반)을 본다.

**Production acceptance (관찰가능):** prod-like 환경에서 로그인 회원이 `/home`(또는 `/`) 진입 → 취향관 탭에 *내 직군 추천 캐러셀 + 직군별 크로스 트렌드(칩 재필터 동작)* 가 Figma 프레임과 1:1로 렌더 → 세그먼트 토글로 피드 탭 전환 → 피드에서 카테고리 칩으로 필터 → 카드 클릭 시 u4 상세 경로로 이동. 데이터 0건이면 콜드스타트 폴백/빈 상태가 보인다. QA가 clean checkout에서 e2e 재현.

### Acceptance criteria  (스토리에서 도출 · 관찰가능 · 각 항목 → L1-x 추적)
**BE** (owner=both — *읽기 전용 소비*; 신규 추천/트렌드 표면은 §ESCALATION E1 결정 후)
- [behavior] 홈은 **u0b가 락한 RLS-safe 읽기 경로만** 사용한다 — 클라가 cross-user `clips` 직접 쿼리 ❌, content 메타는 public-read `contents`, 코호트/소셜은 sanitized view/RPC 경유. → L1-a/c
- [behavior] **추천/트렌드 데이터 표면**: "내 직군이 많이 본 콘텐츠"·"직군별 크로스 트렌드"·"실시간 인기 그랩"은 (1) u0b에 RPC가 있으면 그걸 호출, (2) 없으면 **ADR-0002 #7 콜드스타트 폴백**(전역 인기·에디토리얼 시드·온보딩 관심사) 인터페이스로 채운다. *신규 RPC 필요 여부 = E1 결정.* → L1-a/d/f
- [negative] 추천 RPC/뷰가 user_id·실명·display_name을 노출하지 않음(u0b `derived-api-no-leak` 계약 보존 — 홈에서 cross-user 식별자 표시 ❌). → L1-a

5. **우측 레일 `사이드바_우측`(내 취향에 맞는 실시간 그랩, 420px)** — 풀스크롤 프레임엔 있으나 AI 패널과 위치가 겹침. AI 패널(제거)과 **별개의 추천 레일**로 보임. 포함 여부 = **E4.**

### ESCALATION 후보 (PM/사용자 결정 필요)
- **E1 [추천/트렌드 데이터 표면]** *(가장 중요)*: u0b는 sanitized read·히트맵 RPC는 있으나 **"내 직군 많이 본 콘텐츠"·"직군별 크로스 트렌드"·"실시간 인기 그랩" 집계 RPC는 없음**(콜드스타트 폴백 인터페이스 스텁만, ADR-0002 #7). MVP에서 (a) **단순 인기 집계 RPC 신규**(BE 서브작업 — 마이그+pgTAP no-leak) vs (b) **폴백/시드만으로 화면 채움**(BE 변경 0, 추후 RPC). → owner/마이그 유무가 갈림.
- **E2 [비회원 홈 정책]**: 비회원이 취향관 홈을 보는가(공개 sanitized) vs 온보딩/로그인으로 리다이렉트인가. 톱바 비회원 CTA가 프레임에 있어 *공개 홈* 가능성 — 확정 필요(u1 인증과 연계).
- **E3 [콜드스타트 폴백 카피/시드]**: 데이터 0건 시 "에디토리얼 시드 콘텐츠"를 실제 노출할지, 아니면 빈상태 문구만 둘지(ADR-0002 #7 "또는 문구 제거"). 시드면 시드 출처/큐레이션 주체 필요.
- **E4 [우측 추천 레일 포함 여부]**: `사이드바_우측`(내 취향에 맞는 실시간 그랩)을 u2 범위에 넣을지, AI 패널 제거와 함께 컷할지. (AI 패널과 위치 겹침 — 별개 추천 레일로 판단되나 데이터 표면이 E1과 동일 미비.)
- **E5 [GNB '수신함' 탭]**: FD1로 4탭(홈·검색·라이브러리·수신함) 확정인데 '수신함'(inbox/알림) 대상 화면이 MVP 단위에 없음 — 링크 활성/비활성·라우팅 처리 확인(죽은 링크 ❌ 원칙).
