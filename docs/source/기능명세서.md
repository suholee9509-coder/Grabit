## 1. 프로젝트 개요
---
### 한 줄 정의
성장 콘텐츠 클리핑·큐레이션 서비스

### 제품 목표
외부 성장 콘텐츠(영상·아티클)를 구간/영역 단위로 빠르게 클리핑하고, AI 요약·태그·통계·큐레이션으로 ‘무엇을 봐야 하는지’의 막막함과 FOMO를 줄이며 학습/성장 체감을 높인다.

### 배경
유튜브/퍼블리/브런치/미디엄 등에서 성장 콘텐츠를 소비하지만, 길고 파편화된 정보로 인해 끝까지 보거나 체계적으로 기록·복습하기 어렵다. 또한 ‘남들은 잘하는데 나만 놓치는 것 같다’는 상대적 불안(FOMO)이 존재한다. 크롬 확장 기반 즉시 클리핑과 집단지성(다른 사람의 클립/인사이트), 그리고 AI 요약을 결합해 콘텐츠 소비를 ‘기록→복습→성장 체감’으로 연결한다.

### 사용자 문제
1) 외부 플랫폼에서 유익한 구간을 만나도 즉시 기록/정리하기 번거롭다.
2) 무엇을 봐야 성장에 도움이 되는지 기준이 부족해 탐색 비용이 크다.
3) 저장해도 다시 찾기/복습이 어려워 ‘성장 체감’으로 이어지지 않는다.
4) 유사 직군/연차의 트렌드 정보를 얻기 어려워 FOMO가 커진다.

### 해결 방안
- 크롬 확장 프로그램으로 영상 타임스탬프/아티클 텍스트 영역을 원클릭(또는 드래그) 클리핑 + 플로팅 메모 입력
- 클립 서버 전송 후 자동 라이브러리화(폴더/태그/검색/정렬)
- AI 요약(한 줄/핵심 3줄/상세) + 키워드/자동 태그로 빠른 이해 지원
- 콘텐츠 상세에서 전체 클립(익명)과 밀도 히트맵/하이라이트 오버레이 제공
- 홈에서 트렌드 기반 추천 및 대시보드/통계(또래 비교)로 성장 피드백 제공

### 차별점
- ‘구간 단위’ 클리핑(영상 타임스탬프/아티클 DOM 위치)로 복습 효율 극대화
- 콘텐츠별 소셜 애노테이션(전체 클립 밀도/하이라이트)로 집단지성 탐색
- AI 요약/태그를 클리핑 흐름에 내장하여 기록→이해→정리까지 자동화
- 유사 프로필(직군/연차/관심사) 기반 트렌드 추천과 또래 비교로 FOMO를 데이터로 전환

### 타겟 사용자
- 성장/커리어 콘텐츠를 자주 소비하지만 정리가 어려운 사용자(취준생~10년차)
- 직무: PM, 디자이너, 개발자, 마케터 등
- 상황: 취업 준비/이직 준비/스킬업/승진 준비/커리어 전환/유지
- 니즈: 핵심 구간만 기록, 나와 비슷한 사람들의 트렌드 파악, 다시보기(복습) 효율화

### 사용자 시나리오
1) 온보딩에서 직업/연차/상황/관심분야 선택 → 홈에서 개인화 트렌드 피드 확인
2) 유튜브 시청 중 [📌 클립] 버튼 클릭 → 타임스탬프 자동 저장 → 플로팅 메모 입력 → 서버 전송
3) 저장된 콘텐츠 상세에서 AI 요약 확인 → 타임라인 히트맵으로 중요한 구간 탐색 → 다른 사람 인사이트 열람
4) 라이브러리에서 태그/플랫폼/날짜로 필터링·검색 → 원클릭으로 해당 구간 재생하며 복습
5) 대시보드에서 주간 클립 수/또래 비교/주제 분포 확인 → 다음 주 트렌드 추천으로 탐색

### 핵심 지표
- 확장 프로그램 설치 전환율
- 클립 생성률(DAU 대비 클립 생성 사용자 비율)
- 클립당 메모 작성률
- 저장 콘텐츠 재방문/복습률(클립 재생 클릭률)
- 추천 피드 CTR 및 저장(클립) 전환
- Pro 전환율/유지율(구독 갱신률)

### 리스크
- 저작권/크롤링 이슈: 전체 본문 저장 제한, 요약 중심 제공 및 원본 링크 이동 정책 필요
- 플랫폼별 기술 제약(자막 추출/임베드/DOM 변화)으로 클리핑 안정성 리스크
- 요약 품질/비용(LLM)과 사용자 신뢰
- 개인정보/익명화 정책 미흡 시 커뮤니티 거부감
- 추천/통계의 데이터 콜드스타트

### 카테고리
> 생산성 / 업무

### 사용자 역할
> 비회원, 회원(Free), 회원(Pro)

### 디바이스 (기기)

**수용 기준:**
```

5. ○ 회원 탈퇴 시 Soft Delete(30일 유예) 정책과 복구 안내가 적용된다.
```

> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 비회원, 회원(Free), 회원(Pro) | **기기**: 웹(데스크톱)

## 2. 크롬 확장 기반 클리핑 수집
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전

외부 플랫폼(영상/아티클)에서 구간/영역을 클립하고 메모를 입력해 서버로 전송한다. 중복 클립, 타임스탬프 캡처, DOM 위치 저장을 포함한다.

**수용 기준:**
```
1. ○ 사용자는 크롬 확장 프로그램 설치 가이드를 통해 설치를 완료할 수 있다.
2. ○ 영상에서 현재 재생 시점을 mm:ss 형식 타임스탬프로 캡처해 클립을 생성한다.
3. ○ 아티클에서 텍스트 드래그 시 클립 툴팁이 노출되고 선택 영역(하이라이트) 클립이 저장된다.
4. ○ 클립 시 플로팅 메모 입력창(글자 제한/자동 저장/단축키)을 통해 메모를 저장한다.
5. ○ 동일 구간 재클립 시 ‘이미 클립한 구간’ 안내 후 메모 추가만 수행한다.
```


### 2.1 확장 프로그램 설치 및 권한
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 비회원, 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램, 웹(데스크톱)

Chrome 웹스토어 설치 흐름과 권한 요청(활성 탭, 저장소)을 제공한다.


#### 2.1.1 확장 프로그램 설치 가이드/권한

Chrome 웹스토어 링크 제공 및 설치 단계별 가이드(스킵 가능). 권한 요청: 활성 탭, 저장소.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 비회원, 회원(Free), 회원(Pro) | **기기**: 웹(데스크톱), 크롬 확장 프로그램


### 2.2 영상 타임스탬프 클리핑
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램

유튜브 등 영상에서 [📌 클립] 버튼으로 현재 재생 시점을 캡처해 클립을 생성하고 중복 체크를 수행한다.


#### 2.2.1 클립 버튼 및 타임스탬프 캡처

유튜브 재생 화면에 [📌 클립] 버튼을 오버레이로 노출하고 클릭 시 현재 시점을 mm:ss로 저장한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램


#### 2.2.2 중복 클립 처리

동일 구간 재클립 시 ‘이미 클립한 구간입니다’ 안내 후 기존 클립에 메모만 추가한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램


### 2.3 아티클 텍스트 클리핑
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램

아티클에서 텍스트 선택 감지 및 DOM 위치 저장으로 하이라이트 클립을 생성한다.


#### 2.3.1 텍스트 선택 감지 및 DOM 위치 저장

아티클에서 드래그 시 클립 툴팁을 표시하고 선택 영역 시작/끝 DOM 위치와 선택 텍스트 원본(최대 1000자)을 저장한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램


### 2.4 플로팅 메모 입력 및 서버 전송
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램

클립 직후 플로팅 메모 입력창(자동 저장/단축키/글자 제한)으로 메모를 저장하고 URL+구간/영역+메모를 API로 전송한다.


#### 2.4.1 플로팅 메모 입력창 규칙

플로팅 입력창은 500자 제한, 엔터 저장/ESC 취소, 3초 후 자동 저장을 지원한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전 | **역할**: 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램


#### 2.4.2 클립 서버 전송 및 토스트

URL + 구간/영역 + 메모를 API로 전송하고 성공/실패 토스트 메시지를 노출한다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 시작전 | **역할**: 회원(Free), 회원(Pro) | **기기**: 크롬 확장 프로그램

## 3. 콘텐츠 상세 뷰 및 AI 요약
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 시작전

콘텐츠 메타 정보와 임베드 뷰어(영상/아티클), 원본 링크, AI 요약(한 줄/핵심 3줄/상세) 및 키워드를 제공한다.
